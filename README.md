# ✦ The Lenny Growth Assistant

An evidence-grounded AI growth assistant powered by Lenny's Podcast transcripts.

## What it does

* 🔎 Semantic transcript retrieval
* 🧠 Grounded RAG answers
* 🎙️ Source attribution
* 🦙 Local Ollama inference
* ☁️ Cloud LLM provider support
* ✍️ Ship 30 for 30 content generation
* 🧩 Secure HTML/Markdown artifacts
* ⚡ Streaming responses
* 💾 Persistent conversations
* 🐘 PostgreSQL + pgvector
* 🐳 Docker Compose deployment

## Architecture

```text
Next.js
   ↓
FastAPI
   ↓
RAG + Skills
   ↓
LLM Provider
   ↓
PostgreSQL + pgvector
```
